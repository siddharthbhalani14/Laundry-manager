# Spin — Shared laundry room

A responsive Next.js UI/UX university prototype. Includes a weekly schedule, booking dialog, personal bookings, cancellation, collection confirmation, and demo reminder controls. All interactions use in-memory React state; there is no backend, database, authentication, or delivery of notifications.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy on Vercel

Push this directory to a GitHub repository, import it in Vercel, and select the automatically detected Next.js settings. No environment variables are needed. Build command: `npm run build`.
